# NOTORY

> **Every note tells a story.**

NOTORY is an AI-powered note-taking application that helps users create, organize, search, and enhance notes using Generative AI.

The project is being developed as a Proof of Concept (POC) following professional software engineering practices, including Git Flow, CI/CD, automated testing, security scanning, and AI-assisted development.

---

## Features

- Create, edit and delete notes
- Organize notes with categories
- Search notes
- AI-generated titles
- AI note summarization
- AI writing enhancement
- Responsive user interface
- Secure REST API
- Cloud database integration
